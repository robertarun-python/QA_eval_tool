Evidence discipline - this is the most important rule in this prompt.   - Original defect: the FIRST attempt's own result, judged only against the candidate's oracle for that attempt. If it violated the oracle (e.g. 200 where 4xx was required), that is a real finding, cited with THAT attempt's own turn/quote - it stays true regardless of what any later attempt shows, because a later attempt cannot retroactively change what the system actually returned the first time.   - Subsequent protection: a LATER attempt returning the correct result (e.g. HTTP 409) is real too, but it only shows the system correctly rejected THAT repeat attempt - not that the first attempt's defect didn't happen, and not that the system was correct all along.
